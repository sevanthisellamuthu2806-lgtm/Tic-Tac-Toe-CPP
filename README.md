# Tic Tac Toe Game

A console-based Tic Tac Toe game developed using C++.

## Features

- Two-player game
- 3x3 game board
- Dynamic board display
- Player X and Player O
- Win detection
- Draw detection
- Invalid move checking
- Replay option

## Technologies Used

- C++
- Arrays
- Loops
- Conditional Statements
- Functions
- Console Application

## Project Description

This project is a console-based Tic Tac Toe game for two players.

Players take turns placing X and O on a 3x3 board. The game checks for winning combinations and detects a draw when the board is full.

## How to Run

1. Open the `TicTacToe.cpp` file.
2. Compile the program using a C++ compiler.
3. Run the program.
4. Enter the row and column numbers to make a move.
5. Choose Y or N to play again after the game.
